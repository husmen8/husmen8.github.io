# husmen8.github.io

Personal site, plain HTML and CSS, no build step.

- `index.html`: the page in English
- `ja.html`: the same page in Japanese (change both together)
- `style.css`: the look, shared by both
- `img/`: the small pictures shown on the page (project pictures 480 x 270)
- `photos/`: full-size photos and the poster, opened by clicking
- `docs/`: the CV
